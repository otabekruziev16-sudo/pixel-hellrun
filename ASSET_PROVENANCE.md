# HellRun 2.5 content provenance

This is a development record, not a legal clearance certificate.

| Content | Current source and treatment |
| --- | --- |
| SS+ collection | Twelve original faceless geometric armour designs drawn by `legendary.js`, authored with AI assistance for this project. No anime screenshots, sprites, franchise emblems, costume likenesses or imported character files are used in these replacements. |
| Old SS+ IDs | Names remain only as private save-migration aliases and test fixtures. There are no selectable old characters or old drawing branches in the release renderer. Ownership migrates free in catalog order. |
| Lower-rank cosmetics | Existing procedural pixel designs in `skins.js`; prices and designs preserved. These are not adaptations of the removed named anime characters. |
| Environments and interface | Procedural canvas/CSS geometry in `scenery.js`, `game.js` and `style.css`, including AI-assisted authored artwork. No remotely downloaded art is loaded at runtime. |
| Audio | Original synthesized game sound code in `audio.js`; no anime music, voice clips or third-party recordings. |
| Localization | Eighteen bundled, AI-assisted interface language packs in `i18n.js`; native-speaker editorial review has not been performed. |
| Fonts | Device system fonts referenced by CSS/canvas; no font binaries bundled. |
| Runtime | Electron/Chromium for Windows and Android System WebView on Android. Keep the runtime's bundled third-party license notices in the complete Steam depot. |
| Inherited base game and title | Supplied through the user's existing Pixel HellRun repository. The publisher must confirm ownership/licensing of inherited content and title before commercial submission. |

The new SS+ themes are sun armour, void crystals, ice crown, mechanical clockwork, storm wings, ember drake armour, briar branches, tidal fins, refracting prisms, cracked obsidian, stellar orbits and segmented light panels. Their silhouettes, motion forms and effect motifs are implemented separately. Changing only an old display name is no longer the release strategy.
